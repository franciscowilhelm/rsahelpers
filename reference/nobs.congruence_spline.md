# Number of observations in a fitted congruence spline

Number of observations in a fitted congruence spline

## Usage

``` r
# S3 method for class 'congruence_spline'
nobs(object, ...)
```

## Arguments

- object:

  A `congruence_spline` object.

- ...:

  Unused.

## Value

The number of complete cases used to fit the model.
